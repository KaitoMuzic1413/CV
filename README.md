# CV Cá Nhân - Nguyễn Văn Thái

Trang web CV cá nhân trực tuyến được thiết kế theo phong cách hiện đại, tối giản, hỗ trợ giao diện Tối/Sáng (**Dark/Light Mode**) hoàn toàn bằng **HTML & CSS thuần** (không dùng JavaScript).

**Xem trực tiếp trang web tại:** [https://kaitomuzic1413.github.io/CV/](https://kaitomuzic1413.github.io/CV/)

---

## Tính năng nổi bật

- **Dark / Light Mode:** Chuyển đổi giao diện Sáng/Tối linh hoạt chỉ bằng CSS (`:checked` hack).
- **Responsive Design:** Tối ưu hiển thị đẹp mắt trên cả máy tính lẫn điện thoại di động.
- **Tối ưu hiệu năng:** Code nhẹ, tải nhanh, không phụ thuộc vào thư viện ngoài.

---

## Công nghệ sử dụng

- **HTML5:** Cấu trúc ngữ nghĩa (Semantic HTML).
- **CSS3:** Flexbox, CSS Variables/Transitions, Gradient backgrounds, Media Queries.
